# ZHRAS logo

ZHRAS (Smart RAS Equipment Expert) 영상의 마지막 장면(t≈8.75–10s, 28프레임 평균)에서 추출해 벡터로 재작도한 로고.

| 파일 | 설명 |
|------|------|
| `zhras-emblem-{white,black}.svg/.png` | 육각형 + 물방울 엠블럼 (PNG 2048px, 투명 배경) |
| `zhras-wordmark-{white,black}.svg/.png` | ZHRAS 워드마크 (PNG 3000px, 투명 배경) |
| `zhras-logo-horizontal-{white,black}.svg/.png` | 엠블럼 + 워드마크 가로 조합 (영상에 없는 구성, 편의용) |
| `preview.png` | 어두운/밝은 배경 미리보기 |

## 제작 메모

- 원본 영상은 1280×720이며 엠블럼이 약 50px에 불과해, 프레임 평균 → 업스케일 → 베지어 트레이싱으로 벡터화했다.
- 육각형은 측정값(정육각형, 중심 ≈ 639.9, 277.4 / 선 굵기 ≈ 1px 기준)에 맞춰 기하학적으로 재작도, 물방울 3개(상단 초승달형 / 좌측+우측 대형 연결형 / 하단)와 워드마크는 트레이싱 결과.
- 공식 원본 파일이 아니므로, 인쇄 등 정밀 용도에는 회사 보유 원본(AI/SVG) 사용을 권장.
- 엠블럼 우하단의 작은 점(™/® 추정)은 포함하지 않았다.
- 워드마크는 폰트가 아닌 패스(윤곽선)라 폰트 설치가 필요 없다.
