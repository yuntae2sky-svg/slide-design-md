# ZHRAS SNS 프로필 사진 (PNG, 1080 x 1080)

`../zhras-logo/png/`의 고해상 로고에서 만든 정사각형 프로필 이미지. 정사각형으로 올리면 대부분의 SNS가 원형으로 잘라 보여 주므로, 로고는 원 안쪽(중심에서 반지름 500px 이내, 실제 최대 455px)에 들어오게 맞췄다.

| 로고 | Aqua 배경 `#2A93AE` | Deep Ocean 배경 `#0B3F57` | 흰 배경 |
|------|----------------------|----------------------------|---------|
| **엠블럼** (권장) | `zhras-profile-emblem-aqua.png` | `…-emblem-deep.png` | `…-emblem-white.png` |
| 세로형 | `…-vertical-aqua.png` | `…-vertical-deep.png` | `…-vertical-white.png` |
| 가로형 | `…-horizontal-aqua.png` | `…-horizontal-deep.png` | `…-horizontal-white.png` |

`zhras-profile-all.zip` — 9장 묶음. `preview-circle-crop.png` — 원형으로 잘렸을 때 240 / 110 / 48px 모습.

- 프로필에는 **엠블럼**을 권장한다(48px까지 선명). 세로형·가로형은 `ZHRAS`는 110px에서도 읽히지만 **태그라인·슬로건은 약 200px 이하에서 읽히지 않는다.**
- 흰 배경판은 흰 페이지에서 원 테두리가 사라져 보일 수 있다.
- 배경이 포함된 불투명 PNG다(투명 배경은 프로필에서 지원되지 않는 곳이 많음). 투명 로고는 `../zhras-logo/png/`.
- SNS별 권장 해상도는 바뀔 수 있어 확인하지 않았다. 올리기 전에 해당 SNS의 현재 안내를 확인할 것.
- 중문 버전은 보류 상태라 없다.
