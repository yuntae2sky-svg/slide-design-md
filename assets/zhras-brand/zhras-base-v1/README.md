# ZHRAS 기본형 (Base v1)

**기본형** = Aqua 배경 `#2A93AE` + 평면 그라데이션 B 엠블럼 + Michroma `ZHRAS`(H 원본, 변경 없음) + 태그라인 **Share Tech Mono**(기술적 서체 ③) + 슬로건 Inter.

| 폴더 | 내용 |
|------|------|
| `base/` | 기본형 — 엠블럼 / 가로형 / 세로형 (배경 포함, SVG + PNG) |
| `color-1-deep-ocean/` | 무배경 컬러 ① 글자 Deep Ocean `#0B3F57`, 태그라인 `#136F8A`, 엠블럼 Aqua→Deep |
| `color-2-aqua/` | 무배경 컬러 ② 단색 계열, Aqua Deep `#136F8A` 중심 |
| `color-3-two-tone/` | 무배경 컬러 ③ 글자 Deep Ocean + 선명한 시안→Aqua Deep 엠블럼 |
| `zh-alimama-daoli/` | 중문 `中航环保` · 阿里妈妈刀隶体 (기본 추천, 쐐기형 획끝) |
| `zh-linhai-lishu/` | 중문 `中航环保` · 临海隶书 (대안, 둥글고 넓은 전통 예서) |

무배경 3종은 투명 배경이라 **밝은 배경용**이다(흰 배경 대비: Deep Ocean 11.27:1, Aqua Deep 5.72:1). 어두운 배경에는 `base/`의 흰색 글자 버전을 쓴다.
중문 로고는 기본형 구성(Aqua 배경)에서 `ZHRAS` 자리에 중문을 넣었고, 가로형 / 중·영 병기 가로형 / 세로형이 있다.

## ⚠ 중문 예서체 라이선스 — 사용 전 반드시 확인

서체 파일(TTF)은 저장소에 포함하지 않았고 글자는 윤곽선으로 변환되어 있다. 그러나 **두 예서체 모두 파일 안에 라이선스 문구가 없어 상업 사용 가능 여부를 이 작업에서 확인하지 못했다.**

- 阿里妈妈刀隶体: 저작권 표기 `(c) 2023 阿里巴巴（中国）有限公司`. 알리마마 서체는 무료 상업 사용으로 알려져 있으나(기억에 의존, **미확인**) 공식 약관을 확인해야 한다. 로고 용도(상표 등록 포함)가 허용되는지도 별도 확인 필요.
- 临海隶书: 라이선스 정보를 찾지 못했다. 상업 사용이 허용되는지 불명.
- 제외한 서체: 教育部隶书(대만 교육부)는 CC BY-ND 3.0 대만 라이선스이고 간체 `环`가 없어(번체 `環`만 있음) 광저우 회사 표기에 맞지 않아 쓰지 않았다.

상업 로고로 확정하기 전에 서체 제공처의 약관을 확인하거나, 라이선스가 명확한 서체로 교체하는 것을 권한다.
