- 중문 `中航环保`는 「广州中航环保科技有限公司」의 3~6번째 글자. 레이아웃은 중·영 병기 가로형(`中航环保` + `ZHRAS | SMART RAS EQUIPMENT EXPERT`).
- 태그라인 줄은 기본형과 같은 Share Tech Mono. 투톤 색: 글자 Deep Ocean `#0B3F57`, 태그라인 `#136F8A`, 엠블럼 시안→Aqua Deep 그라데이션.
- 서체 라이선스(파일 내 표기로 확인): ZCOOL QingKe HuangYou = SIL OFL(저작권 `2018 The ZCOOL QingKe HuangYou Project Authors`), Smiley Sans = SIL OFL 1.1(라이선스 전문이 서체 파일에 포함). 라이선스 불명인 钉钉进步体·阿里妈妈数黑体는 제외. 이전에 만든 예서체(阿里妈妈刀隶体·临海隶书)는 라이선스 미확인이라 이 세트에 포함하지 않았다.
- 서체 파일은 저장소에 넣지 않았고 글자는 윤곽선으로 변환되어 있다.

## 컨펌 필요 항목

3. 중문 투톤에서 글자/엠블럼 크기 균형
